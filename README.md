# Fantasy Football Draft Assistant
This is a tool to help give you more information when drafting.

By default it has generated a file summary on each player
These summaries are fed into ChatGPT, to give you some more context when drafting

This is super useful for people like me who play Fantasy Football but don't have a clue who all the players are :)

It's a very extensible tool, and can be easily modified to fit your own rankings & your own summaries!
(just change the [players.csv] and the summaries in the [players/] directory)
