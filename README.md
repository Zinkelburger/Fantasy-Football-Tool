# Fantasy Football Draft Assistant
This is a tool to help give you more information when drafting.

It has a note on each player. Press `q` to feed these summaries into ChatGPT, telling you who to draft.  
This is super useful for people like me who play Fantasy Football but don't have a clue who all the players are :)

It's a very extensible tool, and can be easily modified to fit your own rankings & your own summaries!

Website: [draftassistant.football/](https://draftassistant.football/)

![gui image](gui.png)

## Extension
The browser extension is very simple. Code in `chome-extension/`, download on [Chrome store](https://chromewebstore.google.com/detail/draft-assistant-player-ex/neakbjfmpdmpnibgjeljflnmionbjidi)

# Generating Notes
The note for each player are generated with the scripts in `reddit-scraper/` and gpt-5-nano
